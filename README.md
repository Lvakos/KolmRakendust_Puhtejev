## Juhised programmi käivitamiseks.

1. Kui projekti arhiiv laaditi alla .zip-vormingus, pakkige see lahti.
2. Avage projekti kaust.
3. Leidke fail laiendiga KolmRakendust_Puhtejev.slnx.
4. Topeltklõpsake KolmRakendust_Puhtejev.slnx-failil ja projekt avaneb Visual Studios.
(Kui pole visual studio, siis ülelaadi seda siin: https://visualstudio.microsoft.com/)
5. Kui Visual Studio palub teil puuduvad komponendid installida, installige need Visual Studio installeri abil.
6. Oodake, kuni projekt laadib ja NuGeti paketid taastatakse.
7. Rakenduse käivitamiseks klõpsake nuppu Start või vajutage klahvi F5.
